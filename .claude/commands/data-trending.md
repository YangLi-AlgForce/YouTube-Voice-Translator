# 数据热帖报告生成器 (Data Trending Report)

生成指定主题的数据热帖趋势分析报告。

## 使用方式

```
/data-trending [主题关键词] [平台(可选)]
```

**参数说明：**
- `主题关键词`：要分析的话题，如 AI、比特币、ChatGPT 等
- `平台`（可选）：指定平台，如 微博、知乎、Reddit、Twitter。默认分析全平台

**示例：**
- `/data-trending AI大模型`
- `/data-trending 比特币 知乎`
- `/data-trending ChatGPT Reddit`
